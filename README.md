# 雌雄双厨

手机端私房菜展示网页 — 像线上点单一样选菜，一键生成高级餐厅风格的品鉴菜单。

## 功能

- **点菜**：左侧分类浏览，右侧菜品图文，支持加减选菜
- **生成菜单**：按前菜、主菜、汤品、主食、甜品自动归类，呈现精美菜单
- **我的**：新增/编辑/删除菜品分类，上传菜品图片

数据保存在浏览器本地（localStorage），无需服务器。

## 本地运行

```bash
npm install
npm run dev
```

手机访问：确保手机和电脑在同一 Wi-Fi，用电脑的局域网 IP 打开 Vite 显示的地址。

## 部署

```bash
npm run build
```

将 `dist` 目录部署到任意静态托管（GitHub Pages、Vercel 等）。

## 技术栈

- React + Vite
- 纯前端，localStorage 持久化
