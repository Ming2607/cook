# 雌雄双厨

手机端私房菜展示网页 — 像线上点单一样选菜，一键生成高级餐厅风格的品鉴菜单。

## 功能

- **点菜**：左侧分类浏览，右侧菜品图文，支持加减选菜
- **生成菜单**：按前菜、主菜、汤品、主食、甜品自动归类，呈现精美菜单
- **我的**：新增/编辑/删除菜品分类，上传菜品图片
- **云端同步**（配置腾讯云后）：所有人打开同一链接，看到同一份菜单

## 本地运行

```bash
npm install
cp .env.example .env   # 填入腾讯云环境 ID
npm run dev
```

## 腾讯云同步配置（朋友能看到你上传的菜品）

使用 **腾讯云开发 CloudBase** 存储菜单数据和图片。

### 1. 开通云开发

1. 登录 [腾讯云控制台](https://console.cloud.tencent.com/)
2. 搜索 **云开发 CloudBase** → 新建环境（按量计费，个人使用通常几乎免费）
3. 记下 **环境 ID**（形如 `cook-xxxxx`）

### 2. 开启能力

在云开发控制台中：

| 能力 | 操作 |
|------|------|
| **数据库** | 自动开通即可 |
| **云存储** | 开通，用于存菜品图片 |
| **登录授权** | 开启 **匿名登录** |

### 3. 数据库权限

云开发 → 数据库 → 权限设置 → 新建集合 `menu`（首次保存会自动创建）

开发阶段可将 `menu` 集合权限设为：

- **所有用户可读**
- **所有用户可写**

（家人小范围使用可接受；以后可加管理员密码）

### 4. 配置项目

在项目根目录创建 `.env`：

```
VITE_TCB_ENV_ID=你的环境ID
```

### 5. 构建并发布

```bash
npm run deploy
```

⚠️ **重要**：`npm run deploy` 前必须配置好 `.env`，否则构建出的网页仍是本地模式，朋友看不到你的数据。

### 同步原理

- 菜单数据存在云数据库 `menu/shared` 文档
- 上传的图片存到云存储，所有人访问同一 URL
- 你修改后自动同步，朋友刷新即可看到
